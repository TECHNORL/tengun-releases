# tengun

点群処理ソフト **tengun**（TECHNORL）の配布ページです。

## ダウンロード

[Releases](https://github.com/TECHNORL/tengun-releases/releases/latest) から入手してください。

- **Windows**（64 bit）: `tengun_<版>_x64-setup.exe` を実行します。初回だけ
  「Windows によって PC が保護されました」と出ることがあります。そのときは
  「詳細情報」→「実行」を押してください。
- **Mac**（Apple シリコン）: `tengun_<版>_aarch64.dmg` を開き、tengun を
  アプリケーションフォルダへ入れます。初回だけ、右クリック →「開く」で起動してください。

インストール後は、新しい版が出るとアプリが知らせて更新します。

ライセンスキーが必要です。お問い合わせは TECHNORL まで。
